# Claude Engineering Workflows & Prompts

This file holds reusable workflows so Claude (and other models) stay consistent when expanding the Simple Reset series.

## Instructions for Claude
When you read this file, apply the workflows below to how you expand books, generate marketing assets, and maintain consistency across the repo. Prefer chaining over single long prompts.

## Prompt Chaining Playbook

### 1. Outline → Expand → Polish
- Step A: Create a tight outline for the target section. Free-first, under 150 words.
- Step B: Expand the outline into full text. Keep the locked voice. Add one short series bridge where it helps.
- Step C: Polish. Remove fluff, tighten steps, confirm share-what-worked note is present.

### 2. Voice Lock → Generate → Self-Check
- Step A: From an existing book file, extract the exact voice rules (tone, what to lead with, what to avoid).
- Step B: Generate the new section using only those rules.
- Step C: Compare against the rules, list drifts, and rewrite only the drifted parts.

### 3. Research → Synthesize → Protocol
- Step A: Summarize the strongest practical points on a topic. No unsupported medical claims.
- Step B: Turn the summary into a simple free protocol with time and frequency.
- Step C: Add a one-sentence Geek Out note and a share-what-worked line.

### 4. Series Bridge Chain
- Step A: List the one-sentence bridges that should appear in the current book.
- Step B: Write the matching reverse bridges for the other books.
- Step C: Insert them into the existing core texts without changing the protocols.

### 5. Marketing Asset Chain
- Step A: Extract the 3 most filmable moves from a book core.
- Step B: Write a 45-second vertical video script for each. End with the book link.
- Step C: Turn the same moves into Amazon bullets and a landing-page feature list.

Use these chains. Keep the repo as the single source of truth.
