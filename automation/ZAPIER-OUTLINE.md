# Zapier Automation Outline

## Share-What-Worked to Email/Sheet
Trigger: New form submission (Carrd, Notion, or Google Form)
Actions:
1. Send you an email with the result
2. Add row to a Google Sheet (date, what they did, what changed)
3. Optional: send them the discount code for the next book

## New Book Buyer to Email Sequence
Trigger: New KDP sale notification email (or manual)
Action: Add to Beehiiv/ConvertKit and start the welcome sequence

Zapier is already connected. Once the form and email tool exist, these can be built in minutes.
