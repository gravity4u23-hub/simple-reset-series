# Pre-Upload Checklist (Mandatory)

Before any book goes to KDP:

- [ ] Manuscript read out loud and every step is clear when tired
- [ ] QR codes generated and tested for every demo
- [ ] Clickable links tested in the ebook version
- [ ] Next-book link inserted and correct
- [ ] Share-what-worked link inserted
- [ ] Cover matches series direction and is readable at thumbnail size
- [ ] Description and 7 keywords finalized
- [ ] Categories chosen and accurate
- [ ] Price set ($0.99 launch window planned)
- [ ] Landing page and email sequence live or scheduled for same day

No upload until every box is checked. This is the operating standard.
